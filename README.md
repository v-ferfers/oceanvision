# Ocean Vision — Vinzent Ferfers

Public portfolio website for **Vinzent Ferfers**, highlighting work in **biological oceanography, scientific diving, marine monitoring, underwater imaging and computer vision**.

Live site: https://v-ferfers.github.io/oceanvision/

## Overview

This repository contains the source files for a personal academic and professional portfolio website. The site presents:

- current work in marine monitoring and computer vision
- scientific-diving qualifications and underwater operations
- open-ocean and research-vessel experience
- international study, research and fieldwork experience
- B.Sc. research on Sea Star Wasting Disease
- underwater photography
- CV and contact information

## Main content sections

- **Computer Vision** — annotated benthic-imagery workflows, FishTV monitoring examples and Swedish monitoring work
- **Scientific Diving** — diving qualifications, supervision and applied underwater field methods
- **Open Ocean** — WASCAL Floating University aboard RV Polarstern and offshore sampling experience
- **International Experience** — interactive globe with study, research and fieldwork locations
- **B.Sc. Research** — ecophysiology and monitoring work on *Asterias rubens*
- **Experience** — research, internships, monitoring work and leadership roles
- **Photography** — underwater image gallery

## Repository structure

Typical important files include:

- `index.html` — main portfolio page
- `assets/` — images, videos and static media used by the site
- `README.md` — this repository description
- CV PDF files placed in the repository root or linked location

## Updating the site

To update the portfolio on GitHub Pages:

1. Replace the root `index.html` with the latest version.
2. Upload any new images or videos to the `assets/` folder.
3. Ensure linked filenames match exactly, including capitalization.
4. Commit changes to the `main` branch.
5. Wait for GitHub Pages to redeploy the site.
