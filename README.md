# Vinzent Ferfers — Ocean Vision portfolio

This is a static one-page portfolio designed for GitHub Pages.

## Files

- `index.html` — the website
- `assets/vinzent-ferfers.jpg` — portrait extracted from the current CV
- `CV_Vinzent_Ferfers_09_2026_Leadership.pdf` — downloadable CV

## Publish on GitHub Pages

1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload everything in this folder, preserving the `assets` folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/ (root)**, then save.
6. Your site will be available at `https://YOURUSERNAME.github.io`.

## Editing after publishing

You can change the site at any time. Edit `index.html` directly on GitHub or locally with an editor such as VS Code, then commit/push the change. GitHub Pages will republish it automatically.

When replacing the CV, either keep the same filename or update the two CV links in `index.html`.

## Privacy note

The public page intentionally does not display the street address or phone number from the CV.
